Import from D&D Beyond

Paste a D&D Beyond character URL or ID below. The character must be set to Public on D&D Beyond (Sharing settings).
A new NPC sheet will be created and all stats, skills, proficiencies, and backstory will be filled in automatically.

Note: This uses D&D Beyond's unofficial character API and requires an active internet connection on the DM's machine. Private characters cannot be imported. Stats, skill/save proficiencies, HP, speed, languages, proficiencies, and backstory are imported automatically. Feats, spell lists, and equipment may require manual review.
